# PerceptPurple
A single perceptron neural network I trained that can (kinda) identify the color purple!
I made this because I learned about perceptrons in an Algorithms class a week ago and thought they were cool!
Couple things to note about why it might suck sometimes:
 1. It has 3 inputs for each color channel (0-255)
 2. I trained it (small dataset)
 3. I coded it (bad at coding)
 4. I trained it (I'm colorblind)
 
 The good news is...
 You can train it yourself! (and code it yourself too idk man)
 I made a shitty little tkinter GUI that generates a random color and then YOU get to pick if the color it generated was purple or not, which it then saves to a .csv file as labeled training data.
 Few other things, the default learning rate is completely arbitrary (my source is I Made It The Fuck Up) but you can set that yourself if you want you little freak.
 This is just a first try at machine learning hopefully in the future I make better things.
